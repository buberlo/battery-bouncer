# Battery Bouncer

> Your texts get judged by your battery level.

Battery Bouncer wraps messaging behavior with a low-battery etiquette layer that stamps outgoing messages as trustworthy or desperate. If you send at 3% battery, your words arrive in a tiny low-charge envelope that the recipient must swipe to open. It becomes a game of preserving charge to maintain texting dignity.

## Features
- Live battery badge that rates each outgoing message for confidence
- Low-battery envelopes that require recipient swipe and delay
- Battery dignity score and streaks for calm texting
- Custom emergency phrases that bypass the bouncer only once per day

## Stack
- SwiftUI
- CloudKit
- Core Data
- UserNotifications

## Getting started
```
Open in Xcode 15+, enable iCloud and local notifications, run the BatteryBouncer target on an iPhone simulator or device, and test low-battery behavior via Simulator > Hardware > Battery.
```
